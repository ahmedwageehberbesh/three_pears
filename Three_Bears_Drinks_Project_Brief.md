# Three Bears Drinks — Project Brief for AI

PROJECT STATUS
The business already has an existing menu based on three bear characters: قطبي, باندا, شهاب. We are NOT starting the brand identity from zero. The attached/reference menu is the visual source of truth for the current identity.

GOAL
Build a modern, playful, premium website that turns the existing menu into an interactive experience and allows customers to build an order and hand it off to WhatsApp or Messenger.

V1 SCOPE
- Hero / brand story
- Three bear sections
- Menu
- Product details
- Cart
- Customer details
- WhatsApp/Messenger order message
- Mobile-first responsive UI
- Arabic RTL with English-ready structure
- Character-specific motion and backgrounds

NOT IN V1
- Online payment
- Authentication
- Loyalty
- Inventory
- Full admin ERP
- Native mobile app

KEY RULE
Never invent products, prices, phone numbers, address, opening hours, or other business facts. Use placeholders/TODOs until the owner supplies them.

VISUAL
Use the existing menu's forest/cartoon/bear identity as the starting point. Upgrade it to modern brand quality; do not turn it into a generic cartoon website.

CORE FLOW
Hero → Bears → Character World → Products → Product Details → Cart → Customer Info → WhatsApp/Messenger

AI WORKFLOW
First analyze and confirm understanding, list missing data, propose architecture and UX, then implement.
